# 🏦 Banking Data Analysis Using SQL

A MySQL-based banking data analysis project focused on exploring customer information, account balances, transactions, loans, and branch performance using SQL queries.

## 🛠️ Tech Stack

- **Database:** MySQL 8.0
- **Tool:** MySQL Workbench
- **Language:** SQL

## 📊 Project Overview

This project involves analyzing banking data across 9 tables containing 6,411 records to extract meaningful insights and perform database operations.

## 🔍 Key SQL Concepts

- **Data Retrieval:** SELECT, WHERE, ORDER BY
- **Joins:** INNER JOIN, LEFT JOIN, SELF JOIN
- **Aggregation:** COUNT, SUM, AVG, GROUP BY, HAVING
- **Advanced SQL:** Subqueries, CTEs, Recursive CTEs, Window Functions
- **Database Objects:** Views, Indexes
- **Transactions:** COMMIT, ROLLBACK, SAVEPOINT, ACID Properties
- **Performance:** EXPLAIN and Indexing

## 📁 Database Tables

1. Customers
2. Branches
3. Accounts
4. Transactions
5. Beneficiaries
6. Loans
7. Loan Payments
8. Cards
9. Employees

## 💡 Key Analysis

- Customer distribution and account balance analysis
- Branch-wise account and loan performance
- Employee salary and reporting hierarchy analysis
- Monthly transaction trends
- Duplicate customer identification
- Transaction analysis and account transfers

## 🎯 Project Objective

To strengthen SQL skills through practical banking data analysis, database management, query optimization, and transaction handling.
